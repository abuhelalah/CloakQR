CloakQR Source code

CloakQR

Create clear, standards-compliant QR codes without sending your text, links, or Wi-Fi credentials anywhere. Desktop, Android, and command line.

Download releasesMPL-2.0 open source

Private by construction

Offline

No telemetry and no application-controlled network access. Generation and settings remain on your device.

Useful formats

Text, URL, email, phone, SMS, Wi-Fi, and location payloads with configurable colours and error correction.

Accessible

Adaptive layouts, keyboard navigation, scalable text, high contrast, four languages, and Arabic RTL support.

Automate it

cloakqr_cli --url https://example.com --output code.svg --ecc H

Generate PNG or SVG files in scripts and pipelines with explicit validation and useful exit codes.
